## 8 · Traps learned 09-24 → 09-25

- **An iteration ask after a "ship it" is not a go** — publish only on a ship / go word for THAT change (§0).
- **Take OTA times from `eas update:view` `createdAt`**, not a log file's mtime or a scheduler line — five ledger times
  were wrong until the audit.
- **Never crop a bake sheet with `sips --cropOffset`** — render each glyph on its own canvas (BX/BY shipped garbage icons).
- **A two-trial A/B is not a receipt** — the `BackHandler` was blamed for the panel's paint flake on 4/4 vs 2/2 and cleared
  by 25 trials (memory `backhandler-listener-unpaints-overlay-2026-09-25`).
- **Bench:** the iPhone 16 Pro simulator `D0487F47` is SHARED and logs as `Jeff` with `update_id` NULL; the private bench
  is the 16 Pro Max `6BE4D10D`. It now carries a swapped OTA-CE-era bundle, location Surrey, signed in as Jeff.
  `simctl location start` must run BEFORE launch; a static location never moves the camera. Report tiles post real
  hazards — test from 51.55, −121.30 and expire the row. The panel auto-closes in 8 s.
- **WhatsApp sending:** when the window is on another Space, background typing silently lands nothing — front it with
  `osascript … set frontmost to true`, then display-scope `computer_batch` (memory `whatsapp-desktop-app-sending`). A
  sleeping display makes `app_screenshot` fail with "audio/video capture failure".
- **`AA_MAP_BUTTONS` / `CAR_MAP_BUTTON_CONFIG` are value-locked statics nobody renders** — the live templates use
  `aaMapButtons()` / `carMapButtonConfig()`; change both, relock the statics.
